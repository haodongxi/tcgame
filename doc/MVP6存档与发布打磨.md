# 三国肉鸽卡牌 Web MVP 0.6：存档与发布打磨

> Created by: haodongsheng  
> Version: 0.6  
> Date: 2026-08-20  
> 基于：`doc/MVP5将魂与羁绊.md` 与当前 `web/` 可玩版本

## 1. 本轮定位

MVP 0.1~0.5 已完成核心玩法、路线构筑、遗物、成长、武将差异和将魂羁绊。本轮目标是把它收敛成一个“可以中断、可以恢复、可以重复验证”的本地试玩版本。

## 2. 本轮必须完成

| 模块 | 内容 | 验收 |
| --- | --- | --- |
| 继续游戏 | 保存当前节点、牌组、兵力、遗物、将魂和战斗状态 | 刷新页面后可以回到中断前页面 |
| 自动存档 | 进入地图、事件、商店、休整、战斗和奖励选择时自动保存 | 关键动作后刷新不丢状态 |
| 重新开始 | 开始新局前清理旧的局内存档 | 新局不继承旧牌组和遗物 |
| 结算清理 | 胜利/失败后清理局内存档，永久材料继续保留 | 结算后只能开始新局或查看永久成长 |
| 入口反馈 | 标题页明确显示“继续出征”或“开始出征” | 玩家知道是否存在未完成对局 |
| 基础稳定性 | 防止费用不足出牌、重复点击奖励、非法节点跳转 | 不产生重复奖励或空白页面 |
| 验收记录 | 文档记录手工测试路径和当前排除项 | 新成员可按文档复测 |

## 3. 明确暂不做

本轮明确不实现以下内容：

- 音效、音乐、音量设置
- 部署到线上、域名、CDN 和线上监控
- 微信小程序工程、分包和平台 API 适配
- 云存档、账号登录和跨设备同步

这些内容保留到本地试玩版本稳定之后，避免平台工程和内容调试相互干扰。

## 4. 存档模型

```text
metaSave: 兵革残片、将校虎符、永久天赋
runSave:  heroId、node、run、battle、selectedCard、reward、screen
```

- `metaSave` 和 `runSave` 使用不同的 `localStorage` key。
- 存档增加 `version` 字段，读取未知版本时放弃局内存档但不影响永久材料。
- 战斗中保存抽牌堆、手牌、弃牌堆、敌方兵力、回合和日志，保证刷新后可以继续当前回合。
- 结算页调用清理函数，不删除永久材料。

## 5. 手工验收路径

1. 开始新局，选择张飞，进入第一场战斗，打出一张牌后刷新页面，确认仍在战斗页。
2. 进入军帐事件，刷新页面，确认事件选择仍可继续。
3. 在黑市购买牌、获得遗物和将魂后刷新，确认所有局内状态保留。
4. 点击“重新开始”，选择另一名主将，确认旧牌组、遗物、将魂和铢钱清空。
5. 战斗失败，确认永久兵革残片增加且标题页显示“开始出征”。
6. 战斗胜利完成 Boss，确认结算后刷新不会回到旧 Boss 战斗。
7. 费用不足、奖励重复点击、已完成节点重复进入，都不能改变非法状态。
8. 在 375px 手机宽度和桌面宽度下检查入口按钮、存档提示和结算信息。

## 6. 完成定义

- 本地刷新可恢复未完成对局。
- 新局与旧局隔离。
- 胜负结算与永久材料逻辑稳定。
- 关键页面无空白状态，错误存档不会破坏永久材料。
- JavaScript 语法和 `git diff --check` 通过。
- 音效、线上部署、微信小程序适配仍保持未实现状态，并在文档中明确记录。
