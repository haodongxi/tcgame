# MVP16 章节结算奖励与局外成长

> Created by: haodongsheng  
> Version: 1.6  
> Date: 2026-08-20

## 1. 本轮目标

让章节推进和整局通关产生可持续的局外反馈：章节完成被记录，三章通关获得永久资源，成就和行军统计可以在中军大帐查看。

## 2. 永久统计

`meta.stats`：

| 字段 | 含义 |
| --- | --- |
| `runs` | 开始整军出征次数 |
| `battlesWon` | 完成奖励结算的胜场次数 |
| `chaptersCleared` | 完成章节 Boss 奖励的次数 |
| `wins` | 完成三章的整局次数 |

旧存档加载时自动补齐缺失字段，不清空已有材料和天赋。

## 3. 成就

- `first-win`：首次完成三章行军。
- `veteran`：累计完成 10 场战斗。
- `three-chapters`：累计完成 3 个章节。

成就只记录解锁状态，当前不提供额外战斗数值，避免破坏已有平衡；后续可扩展为头像、卡背或局外货币奖励。

## 4. 结算奖励

- 每次战斗奖励结算：累计胜场统计。
- 每次章节 Boss 奖励结算：累计章节完成统计。
- 第三章 Boss 奖励结算：兵革残片 +30、将校虎符 +1，并累计一次三章通关。
- 失败结算仍保留原有兵革残片奖励，不计入胜场和章节完成。

## 5. 中军大帐展示

中军大帐新增：

- 出征次数。
- 胜场次数。
- 章节完成次数。
- 三章通关次数。
- 初次凯旋、百战老兵、三章行军成就状态。

## 6. 验收标准

1. 开始新局后出征次数增加一次并持久化。
2. 普通/精英/Boss 战斗在完成对应奖励后正确累计胜场，不因刷新重复累计。
3. 章节 Boss 奖励完成后章节完成数增加。
4. 三章通关后永久资源和通关数增加一次。
5. 旧存档可以正常进入中军大帐，统计缺失时显示 0。
6. `node --check web/src/app.js` 与 `git diff --check` 通过。
