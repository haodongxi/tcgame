# 三国主题 Roguelike 地图与敌人体系设计
对标《杀戮尖塔》的竖版节点地图+构筑循环逻辑，完全贴合三国历史情境做包装，拉长单局总流程、丰富敌人数量与机制差异，解决当前关卡少、敌人单一、流派无法成型的问题。整体以张飞的人生轨迹为主线，分三大章节逐步推进，每章为一张独立可选路线的竖版地图。

---

## 一、地图系统整体设计
### 1.1 章节总架构
单局游戏共三大章，对应三段三国历史进程，难度逐层提升，卡牌构筑空间逐层放大。
| 章节序号 | 章节主题 | 对应历史背景 | 地图总层数 | 核心作用 |
| :--- | :--- | :--- | :--- | :--- |
| 第一章 | 涿郡平乱 | 黄巾起义爆发，张飞随刘备在涿郡起兵剿贼 | 15层 | 基础卡牌积累、流派雏形搭建 |
| 第二章 | 虎牢鏖兵 | 十八路诸侯讨董，张飞随军战于虎牢关一线 | 17层 | 核心卡牌获取、流派初步成型 |
| 第三章 | 徐州争锋 | 刘备领徐州后，对阵吕布、曹操大军 | 19层 | 流派完全成型、挑战终局Boss |

### 1.2 单张地图排布规则
完全对齐《杀戮尖塔》的节点选择逻辑：
1. 地图为**竖版从下往上推进**，底部为起点，顶部为章节Boss节点。
2. 每一层横向分布2–4个节点，玩家只能选择与当前位置**相邻的上一层节点**前进，不可后退。
3. 地图存在多条分支路线：有的路线战斗密集、拿牌多；有的路线功能节点多、偏发育续航；有的路线事件多、随机性强。
4. 中途设有固定汇合层，所有路线都会在此交汇，之后再重新分叉，保证玩家有调整路线的机会。

### 1.3 全节点类型与功能
所有节点均做三国情境化包装，功能覆盖构筑、续航、随机事件三大类：

#### 战斗类节点
- **普通遭遇战**（图标：朴刀）：最基础节点，击败2–3名普通敌军后，从3张随机专属/通用牌中选1张加入牌组。
- **精英敌将**（图标：将旗）：难度更高，1名精英武将+2名亲兵，击败后必定掉落1张稀有级卡牌，并有概率获得1件军械（遗物）。
- **章节Boss**（图标：城寨）：每章终点，固定1名主将+2名近卫，机制完整，击败后进入下一章，必定获得1张传说级卡牌+1件稀有军械。

#### 功能类节点
- **军械铺**（图标：铁匠炉）：对应商店，可花费金币购买卡牌、升级卡牌、删除废牌，刷新稀有牌概率。
- **中军帐**（图标：营帐）：对应休息点，二选一：回复30%最大兵力，或升级1张手牌。
- **裁汰营**（图标：兵符）：免费删除1张手牌，用于精简牌组、提纯流派。
- **藏兵洞**（图标：宝箱）：开启后随机获得金币、1件普通军械或1张随机稀有牌。

#### 事件类节点
- **隐士指路**（图标：老者）：随机事件，可能获得增益（免费升级1张牌、获得临时兵力上限）、也可能触发代价（失去少量兵力、弃置1张牌）。
- **流民投奔**（图标：百姓）：可选择接收流民（获得金币但牌组加入1张累赘牌），或拒绝（无事发生）。
- **粮道遭遇**（图标：粮车）：随机触发：劫粮获得大量金币、或遭遇埋伏进入一场强制普通战斗。

## 二、分章节敌人配置（贴合三国情境）
所有战斗不再是单一敌人，普通战以**2–3人小队**为主，精英战为「1精英+2亲兵」组合，Boss战为「1主将+2近卫」组合，且不同敌人有差异化机制，倒逼不同流派发挥作用。

### 第一章：涿郡平乱（黄巾贼寇主题）
敌人以黄巾军、地方贼寇为主，机制简单、血量偏低，以数量压制为主，适合玩家熟悉狂怒机制、搭建基础流派。

#### 普通战斗组合（共4种，随机触发）
1. **黄巾小卒×2**
   - 单名血量：80
   - 技能：每回合造成25点普攻伤害
   - 特点：双目标，适合练多段攻击牌
2. **黄巾弓手×2 + 黄巾刀盾手×1**
   - 弓手血量60，每回合造成20点远程伤害；刀盾手血量120，每回合叠15点护甲
   - 特点：一坦两输出，初步考验破甲与集火选择
3. **山贼头目×1 + 山贼喽啰×2**
   - 头目血量150，喽啰血量50；头目每3回合蓄力一次造成60点高额伤害
   - 特点：有蓄力爆发机制，考验护甲与打断意识
4. **黄巾术士×1 + 黄巾信徒×2**
   - 术士血量90，每回合给全体回复20点兵力；信徒血量70，普攻20点
   - 特点：有治疗机制，考验爆发秒核心的能力

#### 精英战斗组合（共2种）
1. **黄巾渠帅 程远志 + 黄巾亲兵×2**
   - 程远志血量400，亲兵血量80
   - 机制：程远志每2回合召唤1名黄巾亲兵；普攻造成35点伤害
   - 掉落：稀有牌池权重提升，概率获得基础军械
2. **贼首 周仓（剧情前） + 山匪刀手×2**
   - 周仓血量450，刀手血量90
   - 机制：周仓受到攻击时叠加1层「蛮劲」，每层提升5%伤害，叠满5层释放一次横扫AOE
   - 特点：越打越猛，考验控血与爆发节奏

#### 章节Boss：地公将军 张宝
- 主将血量：800，两侧黄巾符使各200血量
- 核心机制：
  1. 每回合给自身叠加10点护甲，符使存活时护甲翻倍
  2. 每3回合释放「黄天符法」，对玩家造成70点伤害并附加2回合「虚弱」（伤害降低25%）
  3. 击败两名符使后，张宝进入狂暴，攻击频率提升但失去护甲加成
- 设计目的：检验单体爆发+AOE清杂的综合能力，适配「先清小怪再灌Boss」的基础流派逻辑

### 第二章：虎牢鏖兵（西凉军主题）
敌人为董卓麾下西凉军，护甲高、爆发强，开始出现复杂机制，逼迫玩家完善流派核心组件。

#### 普通战斗组合（共4种）
1. **西凉枪兵×3**
   - 单名血量120，普攻30点；三名枪兵同时在场时，每次攻击附带5点破甲
   - 特点：多目标+持续削甲，考验护甲续航
2. **西凉重盾手×2**
   - 单名血量200，每回合叠25点护甲，普攻25点
   - 特点：双高甲目标，是破甲流、高爆发流的试金石
3. **飞熊军斥候×2 + 弩手×1**
   - 斥候血量100，弩手血量80；斥候连续攻击2次每次18点，弩手每回合造成35点远程伤害
   - 特点：高频多段伤害，卖血叠怒流派收益高但风险大
4. **西凉监军×1 + 士兵×2**
   - 监军血量180，士兵血量100；监军每回合给士兵加「激昂」buff，士兵伤害提升30%
   - 特点：优先秒核心，否则伤害压力逐层递增

#### 精英战斗组合（共2种）
1. **西凉骁将 华雄部将 胡轸 + 亲兵×2**
   - 胡轸血量600，亲兵血量120
   - 机制：胡轸每回合获得20点护甲，击杀亲兵后会立即补充1名；自身普攻造成45点伤害
   - 特点：无限补兵+叠甲，适合高爆发秒主将，或多段AOE持续清场
2. **飞熊军百夫长 + 锐士×2**
   - 百夫长血量550，锐士血量130
   - 机制：百夫长每3回合释放「冲锋」，造成100点高额单体伤害；锐士普攻附带流血效果
   - 特点：有定时大招，考验防御牌规划与吸血续航能力

#### 章节Boss：骁骑校尉 华雄
- 主将血量：1200，两侧西凉近卫各300血量
- 核心机制：
  1. 被动「连战」：每击杀玩家一次（玩家血量归零前），自身伤害永久提升10%
  2. 每2回合释放「斩击」，对玩家造成80点伤害，同时破除玩家当前50%护甲
  3. 近卫存活时，华雄每回合额外获得30点护甲；近卫全部阵亡后，华雄进入暴怒，攻击频率从2回合1次变为1回合1次
- 设计目的：检验流派的爆发上限与生存稳定性，防反流、吸血流、爆发流均可找到通关思路

### 第三章：徐州争锋（曹军/陷阵营主题）
敌人为曹操精锐与吕布陷阵营，机制全面、伤害高、血量厚，是完全体流派的终局检验。

#### 普通战斗组合（共4种）
1. **曹军盾兵×2 + 曹军弓手×2**
   - 盾兵血量150、叠甲20/回合；弓手血量100、普攻30点
   - 特点：四目标组合，前坦后射，是AOE多段流的核心检验场景
2. **陷阵营死士×3**
   - 单名血量180，普攻40点；血量低于30%时进入死战状态，伤害翻倍
   - 特点：低血爆发，控血与收尾能力很关键
3. **曹军谋士×1 + 虎贲卫×2**
   - 谋士血量130，虎贲卫血量160；谋士每回合给玩家叠加1层「乏力」（每回合少1点气力），虎贲卫普攻35点
   - 特点：debuff压制，考验速杀核心的爆发能力
4. **吕布斥候骑×2**
   - 单名血量220，每回合攻击2次，每次25点
   - 特点：双高频目标，卖血叠怒收益极高，但容错极低

#### 精英战斗组合（共2种）
1. **曹军于禁 部校尉 + 甲士×2**
   - 校尉血量750，甲士血量180
   - 机制：校尉每回合给全体叠加「严整」buff，受到的首次伤害减半；普攻造成55点伤害
   - 特点：高频减伤，适合多段伤害流派，单次大数字流派被克制
2. **陷阵营副将 高顺部将 + 死士×2**
   - 副将血量800，死士血量200
   - 机制：副将每3回合召唤1名死士；死士阵亡时对玩家造成30点反伤
   - 特点：召唤+反伤，纯AOE流派会被反伤克制，需要搭配续航

#### 章节终局Boss：陷阵营统帅 高顺
- 主将血量：1800，两侧陷阵营统领各400血量
- 核心机制：
  1. 被动「陷阵之志」：自身不会获得任何护甲，但所有伤害提升20%，全程无防御纯对攻
  2. 每回合释放「冲锋突阵」，对玩家造成90点伤害；两名统领存活时，伤害额外追加40点
  3. 每4回合召唤2名陷阵营死士，死士普攻30点，阵亡反伤20点
  4. 血量低于30%时进入死战状态，攻击变为1回合2次，不再召唤士兵
- 设计目的：纯高压对攻场景，完美检验完全体流派的上限：爆发流拼速杀、吸血流拼续航、防反流拼减伤反伤

## 三、流派适配逻辑（解决“流派玩不起来”的核心设计）
1. **足够的构筑周期**：三章合计超50个节点，包含至少8次普通战斗、3次精英战斗、2–3次商店、2次删牌、2次升级机会，足以让玩家拿到核心牌、删除初始废牌、升级关键卡牌，完成完整流派构筑。
2. **差异化敌人倒逼流派分化**：
   - 多小怪组合：适配「狂刃连斩+裂牙补刀+千刃狂潮」的多段群攻流
   - 高甲单体敌人：适配「万夫莫当+燕人咆哮+燕人血脉」的破甲爆发流
   - 高爆发敌人：适配「据水断桥+坚壁反戈+一夫当关」的护甲反伤流
   - 长线消耗战：适配「嗜血咆哮+血债血偿+浴血疯魔」的吸血续航流
3. **路线选择强化构筑策略**：玩家可根据当前流派进度主动选路——缺核心牌就走战斗密集路线，血量危险就走中军帐多的路线，牌组臃肿就走裁汰营路线，完全对齐《杀戮尖塔》的策略深度。
