# 三国肉鸽卡牌 Web MVP 0.2：路线与构筑

> Created by: haodongsheng  
> Version: 0.2  
> Date: 2026-08-19  
> 基于：`doc/MVP规划与技术方案.md` 与当前 `web/` 可玩版本

## 1. 本轮目标

MVP 0.1 已经验证“选将—战斗—奖励—结算”能玩通。本轮不扩展大量武将，而是验证肉鸽游戏最关键的第二个问题：

> 玩家是否会因为路线选择和牌组变化，愿意重新开始一局？

本轮完成后，一局流程从固定的三场战斗升级为：

```text
选将 → 遭遇战 → 分支节点 → 黑市/休整 → 精英战 → Boss
              ↘ 军帐事件 ↗
```

## 2. 本轮范围

### P0：必须完成

| 功能 | 规则 | 验收 |
| --- | --- | --- |
| 分支地图 | 第 2 列在遭遇战和军帐事件中二选一；第 3 列在黑市和休整中二选一 | 每局至少出现 2 次真实路线决策 |
| 牌组延续 | 战斗奖励、事件、商店改动作用于整局牌组 | 下一场战斗能抽到上一节点获得的牌 |
| 兵力延续 | 战斗结束后的兵力带入后续节点 | 休整能回复，事件可能损失兵力 |
| 军帐事件 | 三选一：获得铢钱、招募守备牌并损失兵力、获得过牌牌 | 选择后产生可观察的资源或牌组变化 |
| 黑市 | 三张牌购买；删牌获得少量铢钱 | 铢钱不足时购买按钮无效；牌组至少保留 8 张 |
| 休整 | 回复 70 兵力，或移除一张基础牌 | 选择后进入精英战 |
| 资源 | 铢钱进入本局状态，战斗和事件可改变 | 刷新页面不要求恢复局内进度，但局内节点切换不丢资源 |

### P1：本轮暂不做

- 商店遗物、折扣和随机商品刷新
- 卡牌升级后的独立卡牌 ID
- 将魂掉落和完整羁绊
- 云存档、账号和服务端排行榜
- 正式立绘、音效和复杂动画

## 3. 路线定义

| 列 | 节点 | 进入方式 | 结束方式 |
| ---: | --- | --- | --- |
| 0 | 遭遇战 | 自动出现 | 选择奖励后进入第 1 列 |
| 1 | 遭遇战 / 军帐事件 | 玩家二选一 | 战斗奖励或事件选择后进入第 2 列 |
| 2 | 黑市 / 休整 | 玩家二选一 | 点击离开/选择方案后进入第 3 列 |
| 3 | 精英战 | 自动出现 | 战斗奖励后进入 Boss |
| 4 | Boss | 自动出现 | 胜利结算 |

当前版本采用固定列、局内列内随机二选一，后续再替换为 seed 驱动的地图生成器。先验证节点价值，再验证随机性。

## 4. 牌组与资源规则

### 4.1 牌组

- 开局 10 张。
- 战斗奖励把牌加入整局牌组。
- 军帐事件可加入 1 张牌。
- 黑市可购买 1 张牌，也可以删去牌。
- 牌组最少保留 8 张，避免玩家把牌组删空导致体验异常。

### 4.2 局内资源

- 初始铢钱：80。
- 普通战斗奖励：25 + 当前节点序号 × 10。
- 事件接济难民：+55 铢钱。
- 黑市商品价格：25 / 35 / 45 铢钱。
- 删牌：获得 10 铢钱，作为 MVP 中的简化规则。
- 失败时铢钱和牌组清空；兵革残片仍永久保留。

### 4.3 兵力

- 战斗结束时保留当前兵力。
- 休整回复 70 点，不超过主将上限。
- 招募乡勇损失 25 点兵力，最低保留 1 点。
- 失败结算仍保留本局获得的兵革残片。

## 5. 技术实现约束

- 继续使用当前无构建依赖的 HTML/CSS/JavaScript，保证可以直接打开 `web/index.html`。
- `state.run` 统一保存整局牌组、铢钱和兵力；`state.battle` 只保存当前战斗临时状态。
- 节点通过 `enterNode(type)` 分发，不在按钮中直接修改多个状态字段。
- 所有节点结束都调用 `advanceNode()`，避免路线推进逻辑散落。
- 本轮暂不引入后端，继续使用 `localStorage` 保存永久材料。

## 6. 验收场景

1. 选择张飞，完成第一场战斗，奖励选择横扫千军；进入下一场战斗时，牌组中仍有横扫千军。
2. 选择军帐事件“招募乡勇”；进入下一场战斗后能看到列阵防御，兵力少 25。
3. 选择黑市，铢钱足够时能购买牌；不足时点击无效。
4. 黑市删牌后牌组减少 1 张并增加 10 铢钱，牌组少于 8 张时不能继续删。
5. 选择休整后兵力增加；不论选哪条路线都能进入精英战。
6. 精英战胜利后进入 Boss，Boss 胜利显示凯旋入帐并增加永久材料。
7. 失败后重新开始，上一局的铢钱、牌组和兵力不会污染新的一局。
8. 手机宽度 375px 和桌面宽度 1440px 下，路线按钮、商店商品和战斗手牌均可操作。

## 7. 本轮完成定义

- 代码中存在可复用的节点分发和局内状态。
- 玩家至少能玩出两条不同路线。
- 牌组和兵力跨节点延续。
- 事件、黑市、休整均有明确反馈。
- README 和本文件能说明如何运行和验证。
- 本地 Git 提交完成；推送受网络影响时保留清晰提交号。
