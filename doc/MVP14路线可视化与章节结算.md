# MVP14 路线可视化与章节结算

> Created by: haodongsheng  
> Version: 1.4  
> Date: 2026-08-20

## 1. 本轮目标

在三章路线已经可推进的基础上，补足玩家对“我走过哪里、现在在哪里、接下来有哪些节点”的认知，并让完成三章后的结算明确表达整局完成度。

## 2. 路线视图

- 地图保留当前节点前后 5 层，避免手机端出现长页面滚动。
- 每一层显示该层配置中的节点类型，而不是只显示第一项节点。
- 已经过的层使用完成样式，当前层使用高亮样式，未来层使用弱化样式。
- 当前节点可选择的具体路线仍通过下方按钮进入，避免点击地图装饰节点产生歧义。

## 3. 路径回顾

行军存档新增 `run.path`：

```text
[{ chapter, node, type }]
```

每次从地图进入节点时记录一次。地图下方显示最近 5 次行军节点，刷新或继续出征后保留，帮助玩家回顾当前构筑路线。

旧存档没有 `path` 字段时自动初始化为空数组。

## 4. 章节结算

- 第一章、第二章 Boss 奖励完成后进入下一章地图。
- 第三章 Boss 奖励完成后进入“三章凯旋 · 行军完成”结算页。
- 结算页展示完成章节数、本局兵革残片和永久累计材料。
- 失败结算仍保留“兵败暂退”，不影响永久材料存档。

## 5. 验收标准

1. 地图同时展示已完成、当前和未来节点层。
2. 每层能看到配置中的节点类型，手机端文字不会撑破地图卡片。
3. 进入节点后，最近行军记录会更新，刷新后继续保留。
4. 三章全部完成后，结算页显示 3/3 和“三章凯旋”。
5. 地图和结算页不引入新的页面滚动。
6. `node --check web/src/app.js` 与 `git diff --check` 通过。
