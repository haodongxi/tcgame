# 最终文档校对与 MVP 收尾

> Created by: haodongsheng  
> Version: 1.0  
> Date: 2026-08-20

## 1. 校对结论

本轮以最初的《MVP规划与技术方案.md》《基础卡牌.md》《路线与敌人更新.md》《卡牌交互.md》以及基础卡牌/张飞专属卡牌 Excel 为基准，对当前 `web/` 实现进行核对。

## 2. 已对齐内容

- 三名主将入口、张飞狂怒、诸葛亮神机、赵云龙胆基础框架。
- 基础牌 3 张、张飞 18 张专属牌和仓库卡面图片路径。
- 张飞初始牌组：挺矛直刺 ×5、列阵防御 ×4、燕人咆哮 ×1。
- 点击卡牌选中，再点击敌方目标出牌；空白和 Esc 取消。
- 多敌人目标选择、敌方意图、敌方回合和 Boss 特殊机制。
- 三章 15/17/19 层路线、事件/商店/休息/精英/Boss 节点。
- localStorage 永久材料、当前局存档、旧存档字段补齐。
- 手机与电脑响应式布局、单屏战斗区、日志自动滚动和卡牌图片资源。

## 3. 有意调整或尚未完全等同的内容

| 原文要求 | 当前实现 | 处理结论 |
| --- | --- | --- |
| 原规划建议 Vite + React + TypeScript | 当前为原生 HTML/CSS/JS | MVP 仍可运行；零构建更适合当前 GitHub Pages 静态发布，后续若多人协作再迁移 |
| 原规划建议 Vitest/Playwright | 当前使用零依赖 Node 冒烟测试，覆盖核心页面、路线、存档、随机和敌人机制；浏览器实测继续作为 UI 验收 | 尚未引入完整端到端测试框架，复杂交互仍需浏览器手工复测 |
| 卡牌交互要求 scale(1.45)、translateY(-90px) | 当前采用容器内安全上浮，避免手机端 overflow 裁减 | 视觉效果保留，但参数为兼容单屏布局而调整 |
| 原始规划中的随机 seed | 每局生成并持久化 `seed` 与 `rngState`，洗牌、敌人组和将魂选择使用可复现随机序列 | 已补齐；旧存档继续游戏时自动补字段 |
| 原始路线文档中的部分召唤/治疗/流血/反伤细节 | 普通敌人、精英和 Boss 统一支持治疗、召唤、多段攻击、蓄力、破甲、流血、虚弱、增伤和阵亡反伤等词条 | 已补齐；仍保留少量未进入当前牌池的扩展词条 |
| 音效、线上部署、微信小程序 | 当前明确未实现 | 按用户要求暂不做 |

## 4. 最终 MVP 范围

MVP1~MVP18 的玩法、路线、Boss、局外成长和核心 UI 闭环已完成；剩余工作属于工程化、内容扩展和用户明确暂缓的方向，不再继续扩大本轮 MVP 范围。

## 5. 收尾测试

- `node --check web/src/app.js`
- `git diff --check`
- `npm test`（30 个冒烟用例通过）
- 卡牌资源引用数量与 `web/public/assets/cards` 文件数量一致。
- 旧存档字段：`chapter`、`run.path`、`battle.enemies`、`meta.stats`、`meta.achievements`、`meta.cardBack` 均有兼容默认值。
- 旧局存档的 `run.seed`、`run.rngState`、`battle.player.bleed` 等新字段均有兼容默认值。
- 本地静态服务器浏览器实测：21 张卡牌图片均成功加载，无控制台 error/warning。
- 1280px 电脑视口实测：选中卡牌边界完整，图片自然宽度正常。
- 375px 手机视口实测：页面 `scrollWidth === clientWidth`，选中卡牌不超出手牌容器，卡牌图片全部加载。
