# 类杀戮尖塔 卡牌手牌交互系统规范
本文档完整描述手牌收紧排布、悬停放大、选中出牌、抽牌弃牌的全套交互逻辑与动效参数，可直接用于前端代码实现。整体对标《杀戮尖塔》手牌操作手感，适配竖版水墨三国卡牌样式。

---

## 一、系统概述
### 1.1 核心交互原则
- **默认收紧**：手牌区以重叠紧凑的方式横向排列，节省屏幕空间，保证手牌数量较多时依然完整可见。
- **悬停放大**：鼠标指向单张卡牌时，该卡牌放大上浮并置顶，清晰展示完整卡面信息。
- **选中确认**：点击卡牌进入选中状态，再次点击目标/拖拽释放完成出牌，支持点击取消。
- **流畅动效**：所有状态切换均带过渡动画，位移、缩放、透明度统一缓动曲线，保证手感一致。

### 1.2 基础坐标约定
- 屏幕底部为手牌区容器，水平居中排布。
- 卡牌锚点为底部中心点，便于控制上浮与缩放。
- 层级规则：越靠近鼠标悬停位置，z-index 越高。

---

## 二、手牌区域与默认排布（收紧状态）
### 2.1 容器规则
- 手牌容器固定在屏幕底部，宽度占屏幕宽度 85%，高度为卡牌默认高度的 1.2 倍。
- 容器水平居中，底部贴边，内部卡牌沿水平弧线（轻微扇形）排布。
- 手牌数量上限：默认 10 张，超出后继续压缩重叠间距。

### 2.2 单卡默认状态
| 参数项 | 数值 | 说明 |
| :--- | :--- | :--- |
| 默认宽度 | 160px | 竖版卡牌标准尺寸 |
| 默认高度 | 240px | 等比例缩放 |
| 默认缩放 | scale(1) | 基准尺寸 |
| 默认透明度 | opacity: 1 | 全部可见 |
| 默认圆角 | 8px | 与卡面边框一致 |

### 2.3 收紧排布规则
1. **水平间距**
   - 手牌 ≤ 5 张：卡牌水平间距 120px（轻微重叠 40px）。
   - 手牌 6–8 张：水平间距 90px（重叠 70px）。
   - 手牌 9–10 张：水平间距 70px（重叠 90px）。
   - 手牌 > 10 张：水平间距按比例继续缩小，最低 50px。

2. **扇形弧度**
   - 所有卡牌沿一条向下微凸的弧线排列，中间卡牌位置最低，两侧卡牌沿 Y 轴依次抬高。
   - 最左侧与最右侧卡牌相对中间卡牌 Y 轴上移 20–40px，随手牌数量递增。
   - 最左侧卡牌顺时针旋转 3°–8°，最右侧卡牌逆时针旋转 3°–8°，中间卡牌角度为 0°。

3. **层级顺序**
   - 默认从左到右 z-index 递增，保证右侧卡牌覆盖左侧卡牌边缘。
   - 悬停/选中时强制提升层级至最顶部。

## 三、鼠标悬停交互（Hover 放大突出）
### 3.1 触发条件
- 鼠标指针进入卡牌碰撞盒即触发，离开碰撞盒后回退到默认状态。
- 拖拽、选中状态下，悬停效果不覆盖选中效果。

### 3.2 当前悬停卡牌变化
| 参数项 | 数值 | 说明 |
| :--- | :--- | :--- |
| 缩放比例 | scale(1.35) | 放大 35%，清晰展示卡面 |
| Y 轴位移 | translateY(-60px) | 向上浮起，避免被下方边界遮挡 |
| Z 轴层级 | z-index: 999 | 强制置顶，覆盖所有手牌 |
| 旋转角度 | 回归 0° | 取消扇形倾斜，保持卡牌端正 |
| 阴影 | 0 8px 24px rgba(0,0,0,0.4) | 增加悬浮感 |
| 动画时长 | 200ms | 状态过渡时间 |
| 缓动函数 | ease-out | 先快后慢，手感清脆 |

### 3.3 相邻卡牌避让
- 悬停卡牌左侧第 1 张：向左额外平移 20px。
- 悬停卡牌右侧第 1 张：向右额外平移 20px。
- 次相邻卡牌不做避让，避免整体手牌大幅跳动。
- 避让动画与放大动画同步，时长 200ms，ease-out。

### 3.4 信息展示
- 悬停时卡面所有文字保持清晰，无需额外展开描述框（卡面已内置描述区）。
- 若卡牌存在额外说明（如消耗词条解释），可在卡牌右侧弹出小型 tooltip，延迟 300ms 显示。

## 四、选中与出牌交互
### 4.1 选中状态（点击卡牌后）
1. **触发方式**：鼠标左键单击可使用的卡牌。
2. **视觉变化**
   - 缩放：scale(1.45)，比悬停状态更大。
   - 位移：translateY(-90px)，进一步上浮。
   - 边框：卡牌外围增加 3px 金色发光边框，呼吸闪烁（opacity 在 0.7–1 之间循环）。
   - 层级：z-index: 1000，保持最顶部。
   - 其余手牌：整体变暗（opacity: 0.6），突出选中卡牌。
3. **取消选中**：点击空白区域、再次点击该卡牌、按下 ESC 键，均回退到默认状态。

### 4.2 出牌操作（两种模式）
#### 模式 A：点击目标出牌（推荐，对标杀戮尖塔）
1. 点击卡牌进入选中状态。
2. 鼠标移动到敌方目标/出牌区域时，鼠标指针变为“出牌”样式。
3. 点击目标，卡牌从当前位置飞向目标点，完成出牌。
4. 若点击空白区域，则取消选中。

#### 模式 B：拖拽出牌
1. 按住卡牌可拖拽，拖拽过程中保持 scale(1.3)，跟随鼠标位置。
2. 拖拽至敌方目标/出牌区释放，触发出牌动画。
3. 拖拽回手牌区释放，则取消出牌，卡牌归位。

### 4.3 不可使用状态
- 费用不足、条件不满足的卡牌，默认状态下整体亮度降低 40%，并蒙上灰色遮罩。
- 鼠标悬停时依然放大，但不进入选中状态，点击无响应，鼠标指针变为“禁用”样式。
- 卡牌费用数字标红，直观提示费用不足。

## 五、抽牌动画流程
### 5.1 牌堆定位
- 牌堆位于屏幕左下角，堆叠显示剩余牌数。
- 抽牌起点为牌堆顶部中心点。

### 5.2 单张抽牌动画
1. **起始阶段**
   - 从牌堆位置生成一张卡牌副本，初始缩放 scale(0.6)，透明度 opacity: 0。
   - 初始带有 15° 随机旋转角度。
2. **飞行阶段**
   - 沿贝塞尔曲线从牌堆飞到手牌区对应插入位置。
   - 飞行过程中缩放从 0.6 过渡到 1，透明度从 0 过渡到 1。
   - 旋转角度逐渐回归到手牌排布对应的倾斜角。
3. **归位阶段**
   - 到达目标位置后，轻微弹性回弹（scale 1 → 1.05 → 1），融入手牌队列。
   - 其余手牌自动向两侧平移，腾出插入空间。

### 5.3 多张连续抽牌
- 每张卡牌抽牌间隔 120ms，依次飞出，形成连贯的抽牌节奏。
- 例如抽 3 张牌：第 1 张 0ms 出发，第 2 张 120ms 出发，第 3 张 240ms 出发。
- 全部卡牌归位后，手牌重新计算排布位置，整体过渡到收紧状态。

### 5.4 抽牌动画参数
| 参数项 | 数值 |
| :--- | :--- |
| 单张抽牌时长 | 300ms |
| 多张间隔 | 120ms |
| 缓动函数 | ease-out |
| 归位回弹时长 | 150ms |

## 六、出牌、弃牌与消耗动画
### 6.1 出牌生效动画
1. 卡牌从选中位置快速飞向目标点（敌方单位/战场中心）。
2. 飞行过程中缩放逐渐缩小至 scale(0.8)，透明度保持 1。
3. 到达目标位置时，触发对应技能特效（如伤害数字、护盾特效、狂怒图标上浮）。
4. 特效触发后，卡牌进入弃牌/消耗流程。

### 6.2 普通弃牌动画
- 生效后的卡牌从目标位置沿弧线飞向屏幕右下角的弃牌堆。
- 飞行过程中旋转 90°–180°，缩放缩小至 scale(0.5)，透明度逐渐降低。
- 到达弃牌堆后消失，弃牌堆数量 +1。
- 动画时长：400ms，缓动函数 ease-in。

### 6.3 消耗牌动画（带有「消耗」词条的卡牌）
- 生效后不飞向弃牌堆，而是在原地逐渐消散。
- 卡牌从边缘开始向内水墨晕染淡化，伴随轻微向上飘散的粒子效果。
- 透明度在 500ms 内从 1 降到 0，缩放轻微放大至 scale(1.1) 后消失。
- 永久移出本局牌组，不进入弃牌堆。

## 七、卡牌状态视觉规则
| 状态 | 视觉表现 | 交互权限 |
| :--- | :--- | :--- |
| 默认正常 | 原色、正常亮度、收紧排布 | 可悬停、可选中 |
| 费用不足 | 灰度遮罩、亮度 60%、费用数字标红 | 可悬停查看、不可选中 |
| 鼠标悬停 | 放大 1.35 倍、上浮、置顶、加阴影 | 可点击选中 |
| 选中待命 | 放大 1.45 倍、大幅上浮、金色发光边框 | 可点击目标出牌、可取消 |
| 出牌飞行 | 缩小、向目标移动 | 不可交互 |
| 已消耗 | 水墨消散、透明度归零 | 不可交互 |
| 弃牌飞行 | 缩小旋转、飞向弃牌堆 | 不可交互 |

| 行为 | 时长 | 缩放 | 位移 | 缓动函数 |
| :--- | :--- | :--- | :--- | :--- |

## 九、补充实现建议
1. **性能优化**：使用 CSS transform 与 opacity 实现动画，开启硬件加速，避免重排。
2. **碰撞检测**：悬停判定使用卡牌原始矩形区域，放大后不扩大鼠标热区，防止相邻卡牌误触。
3. **队列控制**：抽牌、出牌动画使用任务队列管理，避免多动画同时触发导致错乱。
4. **手感调试**：可在 10% 范围内微调动画时长与缩放比例，适配不同屏幕尺寸与操作习惯。
