# MVP12 章节 Boss 独有机制

> Created by: haodongsheng  
> Version: 1.2  
> Date: 2026-08-20

## 1. 本轮目标

让三章 Boss 不只是血量更高的普通敌人，而是具有可识别的回合节奏和处理优先级。本轮先实现能直接影响战斗决策的核心机制，复杂动画和音效继续后置。

## 2. Boss 机制

### 第一章：地公将军·张宝

- 偶数回合：获得符法护甲；仍有符使存活时获得 20 护甲，否则获得 10 护甲。
- 每 3 回合：释放「黄天符法」，对玩家造成 70 点伤害，并附加 2 回合「虚弱」。
- 虚弱：受到的敌方伤害降低 25%，每次敌方回合结束减少 1 回合。

### 第二章：骁骑校尉·华雄

- 偶数回合：释放「斩击」，造成 80 点伤害，并先破除玩家当前 50% 护甲。
- 其他回合：维持普通攻击节奏。
- 伤害和精英蓄势继续由现有敌人结算框架处理。

### 第三章：陷阵营统帅·高顺

- 每 4 回合：在 Boss 生命高于 30% 时召唤 2 名陷阵营死士。
- 生命低于 30%：进入死战，普通攻击伤害提升为 2 倍，不再触发召唤。
- 统领和死士继续作为独立目标，可被玩家逐个选择和击破。

## 3. 结算顺序

```text
灼烧 → 眩晕判断 → Boss 专属机制 → 普通攻击/护甲 → 反伤与狂怒 → 回合状态衰减
```

玩家的「虚弱」会在敌方回合完成后衰减；「怒发冲冠」的易伤、反伤和额外狂怒仍按 MVP9 的本回合状态规则结算。

## 4. 兼容要求

- 旧存档缺少 `battle.chapter` 时按第一章兼容处理。
- 旧敌人缺少 `bossPhase` 时按未进入 Boss 阶段处理。
- 召唤出的敌人必须进入 `battle.enemies`，并自动参与目标选择、敌方行动和奖励判定。

## 5. 验收标准

1. 张宝每 3 回合日志出现黄天符法，玩家能看到虚弱造成的伤害降低。
2. 华雄偶数回合先减少玩家护甲，再造成斩击伤害。
3. 高顺第 4 回合及之后按节奏召唤死士；低于 30% 后不再召唤且攻击明显提升。
4. 召唤单位显示在敌方区域，可选择、可击杀、会参与敌方行动。
5. 普通战、精英战和非 Boss 敌人行为不受影响。
6. `node --check web/src/app.js` 与 `git diff --check` 通过。
