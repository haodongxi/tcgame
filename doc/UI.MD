# UI视觉与交互规范（适配参考设计稿）
本章节基于参考水墨三国风格设计稿，结合「杀戮尖塔」式手牌收紧/展开交互逻辑制定，适配微信小程序竖屏操作场景，可直接补充入整体策划文档。

---

## 1. 整体视觉风格
- **题材调性**：厚重水墨国风三国，古战场氛围感，写实偏写意的武将美术风格
- **主配色**：墨黑底色 + 米白卷轴/卡片底色 + 朱砂红强调色 + 暗金色装饰线条
- **视觉元素**：淡墨山水行军背景、卷轴式容器、武将头像、传统回纹装饰；弱化冗余特效，优先保证文字信息可读性
- **适配标准**：竖屏750rpx标准尺寸，兼容主流智能手机屏幕，单手操作区域集中在屏幕下半部分

---

## 2. 竖屏界面分层结构（从上至下）
| 区域名称 | 占屏高度占比 | 核心功能 |
| :--- | :--- | :--- |
| 顶部敌方信息区 | 22% | 展示敌方武将属性、状态、下回合行动意图 |
| 中部战斗日志区 | 33% | 卷轴式展示战斗事件流水，支持上下滚动 |
| 我方状态栏 | 15% | 展示我方武将兵力、护甲、气力、核心机制层数、buff状态 |
| 底部手牌操作区 | 30% | 手牌展示、滑动选择、卡牌打出、回合结束操作 |

---

## 3. 各区域详细设计规范
### （1）顶部敌方信息区
1.  **左上角头像**：圆形武将头像，带古风装饰边框，突出敌方身份
2.  **头像右侧信息行**
    - 第一行：敌方武将名称（大字） + 兵力数值「当前/上限」
    - 第二行：兵力进度条（朱砂红填充，实时更新）
3.  **状态标签栏**：名称右侧横向排列，包含护甲值、状态效果标签（如「眩晕」「易伤」）；正面状态用金底，负面状态用红底，均配对应图标
4.  **意图提示条**：头像下方通栏展示，文字格式为「下回合：XX行动」，明确预告敌方下一回合动作
5.  **背景层**：淡墨古战场行军图，低透明度处理，不遮挡前景文字信息

### （2）中部战斗日志区
1.  **容器样式**：竖版卷轴卡片，米白色底，深色细描边，上下带卷轴轴头装饰
2.  **标题**：卷轴顶部居中显示「战斗日志」，配两侧装饰纹样
3.  **内容规则**
    - 按时间顺序从上到下排列，最新事件自动滚动至底部
    - 每条事件前配圆形勾选图标，文字左对齐
    - 记录内容包含：技能伤害、机制触发、物品获取、状态变化、羁绊激活等
4.  **交互**：内容超出卷轴高度后，支持上下滑动查看历史记录

### （3）我方状态栏
1.  **容器样式**：横向长卡片，米白色底，左侧配红色菱形「我」字标识
2.  **左侧**：我方武将方形头像，带深色边框
3.  **右侧信息区**
    - 上排：武将名称（大字） + 兵力数值 + 护甲数值
    - 下排：气力值（格式「气力X/X」） + 核心机制层数（如「狂怒10层」） + 其他buff图标
4.  所有状态均采用「图标+文字」形式，信息层级清晰，一眼可读取核心状态

### （4）底部手牌操作区
1.  **分区标题**：顶部居中显示「手牌」二字，配左右对称装饰箭头
2.  **手牌排列区**：卡牌横向一字排开，支持左右平滑滑动
3.  **分页指示器**：底部中央展示，格式为「当前页/总页数」（如 `1/2`），两侧配滑动箭头
4.  **功能按钮**：右下角放置主操作按钮（结束回合/确认等），圆形金边样式，醒目且不遮挡手牌

## 4. 手牌交互核心规则（杀戮尖塔式）
### （1）常态收紧状态
- 默认横向紧凑排列，单屏完整展示5张卡牌，超出部分露出边缘，提示可滑动
- 每张卡牌固定展示三个信息：
  1.  左上角：金色圆形费用角标，标注气力消耗
  2.  中部：武将/技能主题卡面图
  3.  底部：卡牌名称文字
- 卡牌尺寸统一，文字不溢出，单手可精准点击，适配拇指操作范围

### （2）选中放大状态
- 点击任意手牌，该卡牌**向上弹出放大**，居中突出显示
- 放大后的卡牌新增展示：完整效果描述文字、卡牌类型标签（武技/守备/计策/专属）
- 两侧未选中的卡牌自动轻微缩小、向两侧避让，弱化显示，强化当前选中项的视觉焦点
- 再次点击卡牌外区域，或点击其他卡牌，自动收回至常态

### （3）卡牌打出操作
- 选中状态下，再次点击卡牌，或向上拖拽卡牌至战斗日志区域，即可成功打出
- 卡牌打出后从手牌区消失，后方卡牌自动向前补位
- 打出效果同步更新至战斗日志，并实时刷新敌我双方属性

### （4）满上限滚动规则
- 手牌基础上限10张，默认分为2页展示（每页5张），与底部分页指示器对应
- 支持左右横向平滑滑动切换，无生硬分页跳变
- 手牌数量≤5张时，分页指示器自动隐藏，卡牌居中排列

## 5. 通用控件与样式规范
1.  **字体规范**：标题类使用书法风格字体，正文使用清晰黑体，兼顾国风氛围与长时间阅读舒适度
2.  **按钮样式**：主操作按钮为米白底+深色描边+暗金装饰，点击有按压缩放反馈
3.  **状态标识**
    - 正面增益：金/绿色系标签与图标
    - 负面减益：红/暗灰色系标签与图标
    - 核心机制层数：专属图标+数字，固定位置展示
4.  **动效原则**：所有切换、弹出、打出动效控制在0.2-0.3秒，轻快不拖沓，适配快节奏战斗体验
