# MVP11 章节 Boss 奖励与手牌层级

> Created by: haodongsheng  
> Version: 1.1  
> Date: 2026-08-20

## 1. 本轮目标

本轮处理两个影响体验的高优先级问题：

1. 章节 Boss 击败后，奖励从普通战斗奖励升级为“传说牌 + 军械”的两段选择。
2. 手牌选中上浮时，不能被玩家状态面板、战斗日志或手牌容器的层级遮挡。

## 2. Boss 奖励流程

```text
击败章节 Boss
  → 三张张飞传说牌三选一
  → 三件军械三选一
  → 保存战后兵力与铢钱
  → 进入下一章 / 结束本局
```

当前传说牌候选：

- 万夫莫当
- 裂地猛击
- 燕人血脉

当前军械候选继续复用 MVP5 的基础军械：孙子兵法、青釭剑、行军干粮。后续再增加章节专属军械和动态候选池。

## 3. 手牌层级规则

战斗界面层级从低到高：

1. 战场背景
2. 战斗日志与玩家信息
3. 手牌区域
4. 选中卡牌与出牌动画
5. 奖励弹窗

手牌区域建立独立 stacking context，并保持 `z-index` 高于玩家信息面板。卡牌本身继续使用选中态的 `z-index: 1000`，确保上浮时完整显示。

横向滚动仍只作用于手牌列表，不允许通过提高卡牌层级破坏手牌滚动和单屏布局。

## 4. 验收标准

1. 普通战胜利仍显示普通牌奖励。
2. 精英战胜利仍显示军械后再显示普通牌奖励。
3. 章节 Boss 胜利先显示传说牌奖励，再显示军械奖励，最后进入下一章或结算页。
4. 选中手牌上浮时不被玩家状态区、战斗日志和其他手牌遮挡。
5. 手机和电脑端均不出现额外页面滚动。
6. 刷新后继续存档时，Boss 奖励状态可保持兼容。
