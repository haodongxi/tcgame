# MVP17 统一动效与安全手牌布局

> Created by: haodongsheng  
> Version: 1.7  
> Date: 2026-08-20

## 1. 本轮目标

收敛路线、战斗和手牌的动效参数，并彻底解决选中卡牌在滚动容器中被裁减的问题。

## 2. 手牌裁减修复

根因：手牌列表使用 `overflow-y: hidden` 防止页面滚动，而选中态使用较大的负向位移和缩放，卡牌视觉边界超出列表顶部后会被容器裁掉；单纯增加 `z-index` 无法穿透 overflow 裁剪。

修复策略：

- 为手牌容器预留顶部安全空间。
- 选中态改为容器内安全上浮和缩放，保留金色描边与阴影反馈。
- 保留 `overflow-x: auto`，不引入新的页面横向滚动。
- 手牌区域继续位于玩家状态面板之上，保证层级正确。

这是对原《卡牌交互.md》中 `scale(1.45)、translateY(-90px)` 的兼容性调整：原参数适合不裁剪的独立牌桌容器，但当前项目需要同时满足手机单屏和横向滚动，因此优先保证卡面完整可见。

## 3. 统一动效

CSS 统一变量：

- `--motion-fast`：普通卡牌状态过渡。
- `--motion-card`：出牌/抽牌动效时长预留。
- `--motion-screen`：战斗和节点页面切换。

已接入：

- 进入战斗和节点后的页面过渡。
- 当前地图节点脉冲。
- 卡牌选中、悬停、出牌过渡继续复用统一变量。
- `prefers-reduced-motion` 下自动降级动画。

## 4. 验收标准

1. 手机和电脑端选中卡牌完整显示，不被手牌容器顶部裁剪。
2. 手牌继续只允许横向滚动，页面不产生额外纵向滚动。
3. 选中卡牌仍然明显上浮、描边和置顶。
4. 战斗进入和路线推进有轻量过渡，不造成重复渲染闪烁。
5. 减少动态效果系统设置下动画自动降级。
