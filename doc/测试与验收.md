# 测试与验收规范

## 自动冒烟测试

运行：

```bash
npm test
```

测试入口为 `test/smoke.js`，当前共 33 个用例，覆盖：

- 标题页能渲染并提供开始出征入口。
- 三章路线层数为 15、17、19，且代码路线与章节定义一致。
- 地图使用 1-based 当前层数显示，例如第一章第三层显示 `3/15`。
- 同一个随机种子可以复现相同的随机序列。
- 旧战斗存档能补齐新状态字段。
- 普通敌人治疗、召唤和流血机制生效。
- 路线节点使用固定圆点行和固定文字区，避免章节节点视觉错位。
- 三名主将的初始牌组、卡牌图片资源和路线节点类型。
- 起手五张、气力、抽牌堆循环、狂怒、首击遗物和多敌人目标切换。
- 精英攻击成长、张宝/华雄/高顺三章 Boss 节奏。
- 非法节点、重复路径、事件、商店、休整和费用边界。
- 将魂被动、羁绊、普通/精英/Boss 奖励串联。
- 永久统计、成就一次性奖励、存档版本和存档清理。
- 战斗层级、手牌横向滚动、状态层级和减少动态效果规则。
- 卡牌选择状态的切换/取消、卡牌索引与名称展示、WebP 图片引用、选中放大回弹动画，以及选中牌不向上位移遮挡内容。
- 新战斗不伪高亮默认敌人，攻击牌必须先选牌再点击敌方目标。
- 自用卡牌预览显示“使用”按钮，攻击牌预览显示目标提示。
- 手机竖屏 viewport、媒体查询、手牌横向滚动和预览文本收缩规则。

## 变更要求

每次新增功能或修复 Bug：

1. 先补充或修改对应冒烟用例。
2. 执行 `npm test`。
3. 同时执行 `node --check web/src/app.js` 和 `git diff --check`。
4. 测试未通过时不得视为完成。

冒烟测试用于快速阻止核心回归；涉及移动端尺寸、动画、图片加载和复杂点击路径时，还需要启动静态服务器进行浏览器复测。
