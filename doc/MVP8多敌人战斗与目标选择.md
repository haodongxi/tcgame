# MVP8 多敌人战斗与目标选择

> Created by: haodongsheng  
> Version: 0.8  
> Date: 2026-08-20

## 1. 本轮目标

把当前“单个敌方目标”的战斗框架升级为“敌人组 + 目标选择”，承接《路线与敌人更新.md》中的普通战、精英战和章节 Boss 组合。

本轮重点是战斗骨架和目标交互，不一次性实现所有复杂词条。玩家需要能够看见每个敌人、选择攻击目标、击杀一个敌人后继续攻击其他存活目标，并在敌方回合让所有存活敌人依次行动。

## 2. 敌人组范围

### 第一章普通战

- 黄巾小卒 ×2：80 兵力，25 普攻。
- 黄巾弓手 ×2 + 黄巾刀盾手 ×1：弓手 60 兵力/20 伤害，刀盾手 120 兵力/15 护甲。
- 山贼头目 ×1 + 山贼喽啰 ×2：头目 150 兵力，喽啰 50 兵力。
- 黄巾术士 ×1 + 黄巾信徒 ×2：术士 90 兵力，信徒 70 兵力。

### 第一章精英与 Boss

- 程远志 + 黄巾亲兵 ×2。
- 周仓 + 山匪刀手 ×2。
- 张宝 + 黄巾符使 ×2。

本轮使用现有 `enemyIndex` 作为战斗难度入口，并在每次进入战斗时从对应敌人组中抽取一组。第二、三章敌人组先保留在规划文档与数据接口中，待 MVP10 路线接通后接入。

## 3. 战斗状态设计

```text
battle.enemies[]       当前敌人组
battle.targetIndex      当前选中的敌人
battle.enemy            当前目标的兼容引用
```

`battle.enemy` 暂时保留，指向 `enemies[targetIndex]`，让已有卡牌伤害函数可以渐进迁移。新的多目标卡牌在 MVP9 再统一抽象为 `forEachAliveEnemy` / `hitTarget`。

## 4. 目标交互

1. 点击敌人可以切换当前目标，并显示金色目标框。
2. 点击卡牌进入选中状态，点击任意存活敌人后对该目标结算。
3. 没有选中卡牌时，点击敌人只切换目标，不消耗气力。
4. 敌人死亡后变暗并禁止点击；当前目标死亡时自动切换到第一个存活敌人。
5. 费用不足的卡牌不能进入选中状态。

## 5. 敌方回合

- 所有存活敌人按照从左到右顺序行动。
- 每个敌人的意图显示在自己的敌人卡片内。
- 当前版本保留基础攻击、护甲和灼烧兼容逻辑。
- 召唤、治疗全体、破甲、眩晕、反伤等复杂机制记录到敌人字段，但统一放到 MVP9 效果系统实现。

## 6. 验收标准

1. 普通战至少显示 2 个敌方单位，精英和 Boss 显示 3 个敌方单位。
2. 点击不同敌方单位可以切换目标，目标框不会跟随错误节点。
3. 打出单体攻击牌后，只有当前目标扣血；目标死亡后可以继续攻击其他敌人。
4. 敌方回合所有存活敌人都会行动，死亡敌人不会继续攻击。
5. 敌人组不遮挡战斗日志、我方状态和手牌，手机竖屏仍保持单屏布局。
6. 旧存档只有单个 `battle.enemy` 时可以继续加载，并自动补成单敌人数组。
