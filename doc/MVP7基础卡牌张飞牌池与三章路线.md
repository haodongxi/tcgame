> Created by: haodongsheng  
> Version: 0.7  
> Date: 2026-08-20

## 1. 本轮目标

以新增的《基础卡牌.md》《路线与敌人更新.md》《卡牌交互.md》以及两份 Excel 和卡牌图片为准，替换当前代码中的旧卡牌模型，建立张飞第一版可玩的构筑循环。

本轮优先完成能直接验证手感的内容：

1. 基础卡牌 3 张与张飞专属卡牌 18 张接入真实卡面图片。
2. 张飞初始牌组改为 5 张挺矛直刺、4 张列阵防御、1 张燕人咆哮。
3. 普通牌奖励、商店、删牌规则接入基础牌与张飞牌池的稀有度规则。
4. 卡牌从“点击立即出牌”改为“点击选中 → 点击敌方目标出牌”，支持再次点击取消与空白取消。
5. 手牌使用收紧排列，桌面端悬停放大，移动端点击选中；不以卡牌详情文字撑高牌面，详情由图片承载。
6. 将三章路线和节点类型建立为可扩展数据骨架，先保留当前单场战斗引擎作为兼容层。

## 3. 本轮卡牌规则

### 3.1 基础卡牌

- `挺矛直刺`：1 费，武技，造成 40 伤害，初始 5 张。
- `列阵防御`：1 费，守备，获得 30 护甲，初始 4 张。
- `速攻`：0 费，武技，造成 20 伤害后抽 1 张，初始不带，普通战斗或商店获取。

### 3.2 张飞初始与专属牌池

- 初始牌组：挺矛直刺 ×5、列阵防御 ×4、燕人咆哮 ×1。
- 咆哮突进、据水断桥不再进入初始牌组，转为第一章普通掉落。
- 张飞专属牌以 Excel 的 18 条记录为唯一名称、费用、类型、效果和图片映射来源。
- 本轮先实现已有战斗引擎可表达的效果；破甲、眩晕、反伤、能力和生成牌效果保留明确的数据字段，作为下一阶段多敌人战斗的接入点。

## 4. 本轮交互方案

### 4.1 出牌状态机

```text
默认 → 点击可用卡牌 → 选中待命
选中待命 → 点击敌方状态区 → 出牌结算
选中待命 → 再次点击原卡牌 / 点击空白 / 按 Esc → 取消选中
费用不足或条件不满足 → 不可选中
```

当前战斗仍只有一个敌方目标，因此敌方状态区就是目标区；多敌人接入后沿用同一目标接口。

### 4.2 手牌表现

- 手牌最多 10 张时以负间距收紧排列，避免无意义的横向滑动。
- 桌面端 hover：放大约 1.35 倍、上浮、置顶。
- 选中：放大约 1.45 倍、上浮、金色边框；其他牌降低透明度。
- 移动端不依赖 hover，点击选中后点击敌方状态区确认。
- 卡面图片已包含效果文字，代码不再重复渲染卡牌详情。

## 5. 路线 MVP

先建立三章路线配置，不在本轮一次性重写全部战斗引擎：

- 第一章「涿郡平乱」：15 层，重点出现普通战、军械铺、中军帐、裁汰营和事件。
- 第二章「虎牢鏖兵」：17 层，逐步增加精英战和高护甲敌人。
- 第三章「徐州争锋」：19 层，接入 Boss 节点和终局奖励。

路线配置先支持章节、层数、节点类型、可选分支和敌人组 ID；当前 UI 先展示可行节点，战斗敌人组与多敌人渲染在后续 MVP 接入。

## 6. 验收标准

1. 张飞开局抽到的牌只来自 5 张挺矛直刺、4 张列阵防御、1 张燕人咆哮。
2. 手牌显示真实卡面图片，基础牌与张飞专属牌编号对应正确。
3. 点击牌不会立即结算；选中后点击敌方状态区才出牌，再次点击或点击空白可取消。
4. 桌面端手牌可悬停放大，移动端不因缺少 hover 而无法出牌。
5. 手牌不因卡面长文字产生单牌变高、纵向溢出或页面滚动。
6. 地图数据能区分三章、章节层数和节点类型，现有战斗可继续游玩。
7. 不引入音效、线上部署或微信小程序实现。
