# 三国肉鸽卡牌 Web MVP 0.5：将魂与羁绊

> Created by: haodongsheng  
> Version: 0.5  
> Date: 2026-08-20  
> 基于：`doc/MVP4战斗深度与武将差异.md` 与当前 `web/` 可玩版本

## 1. 本轮目标

前四轮已经完成战斗、路线、牌组、遗物、强化和永久天赋。本轮将“将魂与羁绊”压缩成可验证的最小版本：

- 事件中可以获得将魂。
- 将魂在当前局提供明确的被动效果。
- 主将与特定将魂组合时自动触发一条羁绊。
- 战斗页和日志能解释当前生效的将魂/羁绊。

本轮暂不实现完整将魂谱、重复熔铸、掉落权重和所有历史配方。

## 2. MVP 范围

### P0

| 功能 | 最小规则 | 验收 |
| --- | --- | --- |
| 将魂池 | 周仓、徐庶、廖化 3 枚 | 事件获得后加入本局，并在战斗页显示 |
| 将魂被动 | 每枚将魂 1 个可观察效果 | 出牌、兵力或资源变化能在日志看到 |
| 将魂槽位 | 当前局最多 2 枚 | 已满时事件提示不能继续获得 |
| 羁绊 | 张飞+周仓触发“主仆相随”；诸葛亮+徐庶触发“荐才相知” | 自动显示羁绊名称和效果 |
| 事件入口 | 军帐事件新增“结识旧部”选择 | 选择后获得随机未拥有将魂或得到替代材料 |
| 失败清理 | 将魂和羁绊只属于当前局 | 重新出征时全部清空 |

### P1

- 将魂专属牌
- 重复将魂熔铸和凝练
- 稀有/传说将魂解锁
- 三人完全羁绊和跨阵营彩蛋
- 将魂谱和全局掉落池

## 3. 将魂定义

| 将魂 | 被动 | 与主将的最小羁绊 |
| --- | --- | --- |
| 周仓 | 武技伤害 +5% | 张飞：主仆相随，武技伤害额外 +10% |
| 徐庶 | 计策伤害 +10% | 诸葛亮：荐才相知，神机上限 +2 |
| 廖化 | 最大兵力 +80 | 暂无羁绊 |

将魂被动在当前局生效，主将本身不占将魂槽位。所有被动必须在战斗状态或日志中可解释，避免“拿到了但不知道有什么用”。

## 4. 羁绊规则

```text
主将 + 将魂 → 自动匹配羁绊 → 计算最终战斗参数 → 显示在状态栏
```

当前版本只做二人羁绊：

- 张飞 + 周仓：武技伤害额外 +10%。
- 诸葛亮 + 徐庶：神机上限从 8 提升到 10。

羁绊不需要玩家手动装备或确认；将魂加入后立即触发，离开本局即失效。

## 5. 状态模型

```text
run.souls: string[]
run.relics: string[]
run.upgraded: Record<string, boolean>

activeBonds(run, heroId): string[]
```

- 将魂、遗物、强化牌同属 `runState`。
- `activeBonds` 为纯计算函数，避免在多个页面重复判断。
- 获得重复将魂时，本轮不增加槽位，奖励 15 铢钱作为替代。

## 6. 事件交互

军帐事件新增选项：

```text
结识旧部 → 随机获得未拥有将魂
         → 将魂槽已满或全池重复时，获得 15 铢钱
```

随机只在 3 枚 MVP 将魂池内进行，使用当前随机函数；后续接入 run seed。

## 7. 验收场景

1. 张飞在军帐事件选择“结识旧部”并获得周仓，战斗页显示周仓和“主仆相随”。
2. 张飞携带周仓打出武技，伤害高于没有周仓的同条件伤害，并写入日志。
3. 诸葛亮获得徐庶后，神机上限显示为 10。
4. 获得廖化后主将最大兵力增加 80。
5. 将魂槽已有 2 枚时再次选择将魂，获得 15 铢钱且不新增将魂。
6. 失败或重新开始后，将魂、羁绊和本局被动全部清空。
7. 手机和电脑端的将魂/羁绊标签都能正常换行和阅读。

## 8. 完成定义

- 三枚将魂可获得、可显示、可生效。
- 两条羁绊可自动触发并影响战斗参数。
- 将魂状态不会污染下一局或永久存档。
- JavaScript 语法和 diff 检查通过。
- 形成独立 Git 提交，为 MVP 0.6 发布打磨做准备。
