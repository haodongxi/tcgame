# 三国肉鸽卡牌 Web MVP 0.4：战斗深度与武将差异

> Created by: haodongsheng  
> Version: 0.4  
> Date: 2026-08-19  
> 基于：`doc/MVP3构筑与成长.md` 与当前 `web/` 可玩版本

## 1. 本轮目标

MVP 0.3 已经有路线、牌组、遗物和永久天赋。本轮不增加新的页面，而是提高战斗本身的辨识度：

- 三名主将的核心机制必须在出牌和日志中真实触发。
- 普通敌人、精英和 Boss 必须有可读的行为差异。
- 玩家要能根据敌方意图和自身状态做出下一步决策。

## 2. P0 范围

| 模块 | 规则 | 验收 |
| --- | --- | --- |
| 张飞·狂怒 | 受到伤害时 +1 狂怒；低于 50% 兵力时每次受伤 +2；每层武技伤害 +5% | 兵力、日志、伤害同时体现变化 |
| 诸葛亮·神机 | 打出计策牌 +1 神机，上限 8；神机使计策伤害 +4% | 八阵图、火攻、神机妙算触发增长和强化 |
| 赵云·龙胆 | 每打出 3 张牌追加 40 伤害；计数在战斗状态栏可见 | 第 3、6 张牌后日志出现龙胆连击 |
| 精英行为 | 每 3 回合攻击强化 +20 | 意图和实际伤害一致 |
| Boss 行为 | 兵力低于 50% 后进入暴走，攻击 +20% | 日志显示“暴走”，意图实时更新 |
| 状态提示 | 狂怒、神机、龙胆、灼烧和暴走都有文字提示 | 不依赖颜色才能理解状态 |

## 3. 机制冻结

### 3.1 张飞

```text
受到伤害：狂怒 +1
兵力 < 50%：狂怒 +2
武技伤害：基础伤害 × (1 + 狂怒 × 5%)
```

狂怒上限 10 层。护甲抵消全部伤害时不叠加狂怒，避免防御牌与卖血机制冲突。

### 3.2 诸葛亮

本轮将 `formation`、`fire`、`foresight` 标记为计策牌：

```text
打出计策牌：神机 +1
计策伤害：基础伤害 × (1 + 神机 × 4%)
神机上限：8
```

`八阵图` 额外获得 2 层神机，但本身仍只算 1 张计策牌，避免一次牌触发两次计数。

### 3.3 赵云

每打出任意一张牌计数 +1，达到 3 的倍数时追加 40 伤害并把计数归零。状态栏显示 `龙胆 X/3`。

## 4. 敌方行为

| 敌人 | 基础行为 | 特殊规则 |
| --- | --- | --- |
| 黄巾校尉 | 攻击 35 / 防御 20 轮换 | 无 |
| 虎牢守将 | 攻击 55 / 防御 20 轮换 | 每 3 回合攻击 +20 |
| 董卓亲军 | 攻击 75 / 防御 20 轮换 | 兵力低于 50% 后攻击 +20% |

意图显示必须使用计算后的最终数值，不显示过时的基础数值。每次进入强化状态写入战斗日志。

## 5. UI 调整

- 我方状态栏显示：兵力、护甲、气力、主将机制、遗物。
- 机制名称使用文字而非只显示数字：`狂怒 4层`、`神机 3层`、`龙胆 2/3`。
- Boss 暴走时在敌方信息区追加 `暴走` 标签。
- 战斗日志记录“机制触发 → 数值变化 → 最终结果”，例如：

```text
神机：计策伤害 +12%
火攻造成 98 伤害
```

## 6. 验收场景

1. 用张飞结束回合并受到一次未被护甲完全抵消的攻击，狂怒增加。
2. 张飞低于半血后受到攻击，狂怒一次增加 2 层。
3. 用诸葛亮连续打出八阵图、火攻，神机和火攻伤害均提升。
4. 用赵云打出三张牌，日志出现龙胆连击且状态计数归零。
5. 精英战第 3 回合意图攻击数值提升 20。
6. Boss 低于半血后日志出现暴走，下一次攻击提升 20%。
7. 手机和电脑端的状态栏均能看到机制文字和遗物。

## 7. 完成定义

- 三名主将的机制均有可观察反馈。
- 精英和 Boss 的最终意图数值正确。
- JavaScript 语法和 diff 检查通过。
- 本轮代码和文档形成独立 Git 提交。
