# MVP15 路线分支校验与节点反馈

> Created by: haodongsheng  
> Version: 1.5  
> Date: 2026-08-20

## 1. 本轮目标

让路线分支从“可展示”变成“可校验、可理解”的交互：当前层只能进入配置中存在的节点类型，地图能清楚区分战斗、精英、Boss、商店、休息和事件。

## 2. 可达性规则

入口统一经过：

```text
点击节点 → currentRoute()[state.node] → 查找节点 type → 通过后进入节点
```

- 当前章节和当前层没有配置的节点类型不能进入。
- 重复点击同一个路线按钮不会重复写入 `run.path`。
- 旧存档如果停留在合法层，继续出征仍按当前章节路线校验。
- 不改变现有节点完成后的自动推进规则，避免破坏战斗、事件、商店和休息节点。

## 3. 地图反馈

- 当前节点使用循环脉冲，提示玩家应该从下方分支按钮选择路线。
- 战斗类节点使用朱红色，精英/Boss 使用深金色，休息使用绿色，事件使用紫色，商店使用棕金色。
- 路线按钮按下时轻微缩放，提供移动端点击反馈。
- 地图仍只展示当前节点前后 5 层，维持单屏和手机端不滚动目标。

## 4. 验收标准

1. 通过正常地图按钮进入节点时，战斗流程和节点页面不受影响。
2. 手动构造非法节点类型或旧存档异常输入时，不会进入未配置节点。
3. 连续点击同一按钮不会产生重复路径记录。
4. 地图节点颜色、当前节点动画在手机和电脑端均可辨识。
5. `node --check web/src/app.js` 与 `git diff --check` 通过。
