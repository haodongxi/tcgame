## 一、游戏类型与核心玩法
### 1. 游戏定位
纯文字竖屏DBG（牌库构筑）肉鸽卡牌游戏，三国题材，对标《杀戮尖塔》战斗核心 + 《哈迪斯2》元成长体系，轻量化适配微信小程序，单局时长约15分钟。
无美术卡面，全部以「文字按钮+状态文本」呈现，包体极小、秒开即玩。

### 2. 核心玩法循环
1. **出生点准备**：在「中军大帐」消耗永久材料解锁天赋、武将、将魂权限，选择主将与出征章节
2. **局内推进**：选择分支路线，依次经过战斗、事件、商店、迷雾等节点，获取卡牌、将魂、局内资源
3. **战斗核心**：回合制卡牌对战，消耗气力出牌，通过构筑牌组、叠加武将专属机制击败敌人
4. **结算闭环**：无论通关或战败，局内收集的永久材料全部保留；局内卡牌、将魂、金币全部清零，下一局从零开始构筑
5. **长期成长**：用带回的材料解锁更多内容、强化基底，逐步解锁新武将、新羁绊、新章节，越玩内容越丰富

### 3. 核心特色
- 单武将开局，局内收集将魂补强，凑齐经典组合触发羁绊效果
- 每名武将拥有独有的核心机制与专属牌库，玩法差异显著
- 全随机掉落+全局词条，每局体验不同，Build组合高度自由
- 失败也有正向反馈，永久成长平滑，适配碎片化游玩习惯

## 二、武将系统
### 1. 通用规则
- 每局仅选择1名主将，拥有独立核心机制与专属牌组
- 初始牌组 = 基础通用牌 + 武将专属初始牌，共10张（天赋可精简）
- 进阶专属牌仅对应主将可掉落，通用牌池所有武将均可获取

### 2. 武将详情
#### 武将1：张飞
- **核心机制【狂怒】**：每次受到伤害叠加1层狂怒（上限10层），每层提升5%武技伤害；兵力低于50%时，狂怒叠加速度翻倍
- **定位**：狂怒卖血流，高风险高收益，残血爆发极强，适合偏好暴力输出的玩家
- **初始专属牌（开局自带）**
  1. 咆哮突进（1费·武技）：造成60伤害，获得2层狂怒
  2. 据水断桥（2费·守备）：获得50护甲；消耗3层狂怒，每层额外+10护甲
  3. 燕人咆哮（3费·专属大招）：造成220伤害，消耗当前所有狂怒层数，每层追加12伤害
- **进阶专属牌（局内稀有掉落）**
  1. 裸衣死战（1费·武技）：失去50最大兵力，获得5层狂怒，抽1张牌
  2. 万夫莫当（2费·武技）：造成80伤害；狂怒层数≥5时，附带2回合破甲

#### 武将2：诸葛亮
- **核心机制【神机】**：每打出1张计策牌，叠加1层神机（上限8层），每层提升4%计策效果与控制时长
- **定位**：神机叠策流，靠计策连锁控场+持续灼烧输出，几乎不依赖普攻，适配计策利好词条
- **初始专属牌（开局自带）**
  1. 八阵图（1费·计策）：获得30护甲，叠加2层神机
  2. 火攻（2费·计策）：造成80伤害，附加2回合灼烧（每回合30伤害）
  3. 神机妙算（3费·专属大招）：根据神机层数触发效果：3层→全体易伤；5层→双倍灼烧；8层→250伤害
- **进阶专属牌（局内稀有掉落）**
  1. 借东风（1费·计策）：立即叠加3层神机，本回合所有计策效果+30%
  2. 空城计（0费·守备）：本回合受到的首次伤害无效；手牌为空时，额外获得40护甲

#### 武将3：赵云
- **核心机制【龙胆】**：每打出3张牌，触发一次「龙胆连击」，自动追加一次40伤害的普攻，不消耗气力
- **定位**：龙胆连击流，灵活过牌、持续输出，自带保命能力，容错率最高，适合新手
- **初始专属牌（开局自带）**
  1. 龙胆冲阵（1费·武技）：造成50伤害，抽1张牌
  2. 单骑救主（2费·守备）：获得60护甲，本回合受到的首次伤害无效
  3. 七进七出（3费·专属大招）：连续攻击4次，每次45伤害，每次命中抽1张牌
- **进阶专属牌（局内稀有掉落）**
  1. 银枪破阵（1费·武技）：造成40伤害，本次攻击计入2次龙胆连击计数
  2. 常胜之势（2费·能力牌）：本局内，龙胆连击额外附带15点吸血

## 三、将魂与羁绊系统
### 1. 将魂基础规则
#### （1）核心设定
将魂本质为「英魂战法传承」，获得后可习得对应武将的被动效果与1张专属牌，并非武将本人参战；无典故关联的将魂之间不触发任何羁绊，仅独立生效。

#### （2）槽位限制
普通难度单局最多携带2枚将魂，加上主将共3个魂位；槽位满后不再触发新的将魂掉落。

#### （3）获取渠道（全池等概率纯随机）
1. **最终Boss掉落**：100%掉落1枚随机将魂
2. **精英战斗掉落**：普通难度单场35%概率掉落1枚
3. **迷雾「？」节点**：40%概率触发将魂事件，100%获得1枚
4. **特殊事件分支**：部分事件选项判定成功后，20%~50%概率掉落
5. **黑市商店**：150铢钱购买「将魂盲盒」，随机获得1枚

#### （4）重复将魂处理
掉落已持有的将魂时，二选一：
1. **熔铸换材**：获得兵革残片×3 + 将校虎符碎片×1（3碎片合成1枚完整将校虎符）
2. **凝练强化**：该将魂被动效果提升50%，不新增卡牌、不占额外槽位

#### （5）掉落池解锁规则
将魂逐步解锁进入全局掉落池，初始默认8枚普通将魂，稀有/传说将魂需在铸兵坊解锁掉落权限。

### 3. 羁绊系统
#### （1）核心规则
1. **自动匹配**：主将+携带将魂计入「本局魂组」，系统自动遍历所有羁绊配方，满足即触发，可多羁绊共存
2. **梯度触发**：2人满足触发半羁绊（约45%强度），3人满足触发完全羁绊，人数达标自动覆盖低阶效果
3. **无典故不生效**：无正史/演义交集的武将组合，永不触发羁绊，仅独立生效
4. **不区分主将/将魂**：只要魂组内包含对应武将，羁绊效果完全一致

## 四、元成长与中军大帐系统（对标哈迪斯2）
### 1. 永久材料体系
所有材料无论通关/战败，100%带回中军大帐；局内铢钱、卡牌、将魂战败清零。

| 材料名称 | 稀有度 | 获取途径 | 核心用途 |
| :--- | :--- | :--- | :--- |
| 兵革残片 | 普通 | 普通战斗、精英战斗、事件采集、商店购买 | 解锁/升级韬略阁基础天赋 |
| 将校虎符 | 稀有 | 精英战斗、迷雾节点、将魂熔铸、Boss掉落 | 解锁新武将、将魂掉落权限、高级天赋、机制功能 |
| 龙魂玉 | 传说 | 章节Boss首通、隐藏结局、高难度通关 | 解锁核心羁绊、传说遗物、新章节、噩梦难度 |

### 2. 中军大帐核心功能
#### （1）韬略阁（永久天赋树，对标灰烬祭坛）
消耗兵革残片解锁升级，全武将全局生效，数值加成克制在20%以内，不破坏平衡。
分三大分支：
- **军威线（战斗强化）**
  1. 锐兵：初始兵力+50（可升3级，最高+150）
  2. 利刃：所有武技牌基础伤害+5%（可升3级，最高+15%）
  3. 善谋：所有计策牌效果+5%（可升3级，最高+15%）
  4. 战意：初始气力+0.5（可升2级，最终首回合+1气力）
- **经略线（资源经济）**
  1. 丰饶：初始铢钱+30（可升3级，最高+90）
  2. 商通：商店商品价格-10%（可升2级，最高-20%）
  3. 善收：所有材料掉落数量+15%（可升2级，最高+30%）
  4. 休整：每局首次休整节点回复效果+30%
- **构筑线（牌组灵活性）**
  1. 精简：初始牌组减少1张基础牌（可升2级，最多减2张）
  2. 天眷：开局随机获得1件普通遗物
  3. 将魂扩容：将魂槽位+1（从2格扩到3格）
  4. 巧手：每局免费升级卡牌次数+1

#### （2）铸兵坊（内容与机制解锁，对标咒术大锅）
消耗将校虎符与龙魂玉解锁新内容、新机制，是扩充游戏体量的核心。
- **基础解锁（将校虎符）**
  1. 解锁新武将：关羽、周瑜、司马懿等
  2. 解锁稀有将魂掉落权限：关羽、刘备、周瑜等进入全局池
  3. 解锁功能：商店删卡服务、休整节点卡牌升级功能
  4. 解锁玩法：每日挑战模式、初始遗物槽位
- **顶级解锁（龙魂玉+将校虎符）**
  1. 解锁核心羁绊掉落权限：如桃园结义、五虎上将
  2. 解锁传说初始遗物：如《孙子兵法》
  3. 解锁新章节：赤壁之战、官渡之战
  4. 解锁噩梦难度：敌人血量+50%，材料掉落翻倍
  5. 解锁将魂继承：每局可携带1枚已解锁将魂开局

#### （3）将魂谱
- 首次获得某将魂后自动收录，后续才会进入全局掉落池
- 可消耗将校虎符提升指定将魂的掉落权重，但不打破全池随机规则
- 查看所有将魂、羁绊的图鉴与解锁进度

#### （4）出征入口
选择章节、难度，确认主将后开始对局。

## 五、核心战斗规则
### 1. 基础资源
- **气力（费用）**：每回合固定3点，出牌消耗对应气力，回合结束清零，不继承
- **兵力（生命值）**：主将生命值，归零则战败
- **护甲**：守备牌提供，回合结束后清零，可抵消等额伤害

### 2. 牌库循环
抽牌堆 → 手牌 → 弃牌堆；抽牌堆为空后，弃牌堆洗入抽牌堆重新抽取。

### 3. 回合流程
1. 回合开始：触发回合初效果（如羁绊回血、灼烧掉血）
2. 抽牌阶段：从抽牌堆抽取5张牌到手牌
3. 出牌阶段：消耗气力打出手牌，触发对应效果
4. 结束回合：未打出的手牌全部进入弃牌堆，护甲清零
5. 敌方行动：敌方按预告意图执行攻击/技能

### 4. 手牌规则
- **基础起手**：每回合固定抽5张
- **手牌上限**：基础上限10张，超出部分直接进入弃牌堆
- **特殊词条**：部分卡牌带「保留」词条，回合结束不进入弃牌堆

### 5. 敌方机制
- **敌方意图**：全程显示敌方下回合行动（攻击/防御/技能）与伤害数值，玩家可针对性应对
- **精英/Boss被动**：拥有独特被动技能，如每3回合突袭、概率双倍伤害等

### 6. 常见状态效果
- **灼烧**：回合开始受到固定伤害，可叠加层数/时长
- **易伤**：受到的伤害提升百分比
- **破甲**：护甲值无效化
- **眩晕**：跳过本回合行动
- **伤病**：负面牌，无法打出，占用手牌，回合结束自动移除

## 六、关卡与节点系统
### 1. 章节设定
- 初始章节：虎牢关征讨（共7个节点 + 1个最终Boss）
- 后续可拓展：官渡之战、赤壁之战、长坂坡等

### 2. 路线选择
每局开局二选一：
- **官道进军**：敌人较弱，收益平稳，节点全可见
- **山间险径**：敌人更强，稀有掉落概率提升，包含1个「？」迷雾未知节点

### 3. 节点类型详解
1. **战斗节点**：普通敌将战斗，胜利后获得铢钱、材料、卡牌三选一奖励
2. **精英战斗节点**：强力敌将，高概率掉落将魂、进阶卡牌、稀有材料
3. **事件节点**：剧情选择，不同选项带来不同奖励/惩罚，部分触发连锁事件
4. **商店节点**：消耗铢钱购买卡牌、删卡服务、将魂盲盒、材料
5. **休整节点**：可选择回复兵力、升级一张卡牌、寻访隐士
6. **迷雾「？」节点**：未知类型，进入后随机触发宝藏、埋伏、将魂、黑市等事件
7. **Boss节点**：章节最终首领，胜利必掉龙魂玉、将魂、稀有卡牌

## 七、全局战局词条系统
每局开局随机生成1条全局词条，改变本局基础规则，迫使玩家调整打法。
### 示例词条
1. **大雾弥天**：所有武技牌命中率-10%，所有计策牌效果+20%
2. **疫疠之年**：所有回血效果降低50%
3. **粮草大熟**：初始铢钱+100，商店商品降价20%
4. **将星下凡**：所有敌将武勇+10，但掉落品质提升一级
5. **兵贵神速**：所有战斗最多8回合，8回合未分胜负直接判定战败
6. **背水一战**：无法使用任何回血道具，所有伤害整体+30%

> 高难度下可叠加2-3条词条。

## 八、UI与交互规范
### 1. 竖屏布局结构（从上到下）
1. **顶部敌方区（25%高度）**：敌方名称、兵力条、护甲值、下回合意图、状态图标
2. **中部战斗信息区（40%高度）**：战斗日志滚动栏 + 我方状态条（兵力、护甲、气力、buff/debuff、将魂羁绊生效状态）
3. **底部手牌操作区（35%高度）**：手牌横向排列 + 结束回合按钮

### 2. 手牌交互逻辑（杀戮尖塔式）
1. **常态收紧**：手牌横向紧凑排列，默认显示「费用数字 + 卡牌简称 + 类型色条」
2. **选中放大**：点击任意手牌，该牌向上弹出放大，显示完整效果文字；两侧卡牌轻微缩小避让，突出选中项
3. **超出滚动**：手牌超过5张时，支持左右横向滑动查看；底部显示滚动位置指示
4. **打出操作**：选中状态下再次点击卡牌，或直接拖拽向上释放，即可打出
5. **满上限状态**：10张满手牌时紧凑排列，滑动查看，选中单张放大显示详情，不出现分页按钮

## 九、结算与胜负规则
### 1. 胜利条件
击败章节最终Boss，即为通关。

### 2. 失败条件
主将兵力归零，即为战败。

### 3. 局内清零项（肉鸽核心规则）
- 所有局内获得的卡牌、将魂、铢钱
- 所有局内临时效果、机制层数、遗物
- 牌组构筑进度全部重置，下一局从零开始

### 4. 永久保留项（元成长闭环）
- 所有永久材料：兵革残片、将校虎符、龙魂玉
- 图鉴收录进度：卡牌、将魂、羁绊、遗物
- 韬略阁天赋、铸兵坊解锁内容永久生效
