## 1. 本轮目标

承接 MVP7 的卡牌图片和 MVP8 的多敌人目标系统，把张飞 Excel 中定义的 18 张专属牌从“可显示、部分可用”推进到“效果可结算”。本轮只处理张飞专属机制，不扩展第二、三章地图。

## 2. 状态模型

### 玩家状态

- `rage`：当前狂怒层数。
- `rageCap`：狂怒上限，默认 10，燕人血脉提升至 15。
- `rageMultiplier`：每层狂怒提供的武技伤害倍率，默认 5%，燕人血脉提升至 6%。
- `rageOnHit`：本回合受击时额外获得狂怒。
- `reflect`：本回合受到伤害时反弹伤害。
- `bloodRush`：兵力低于 50% 时武技伤害 +10%。
- `berserk`：兵力低于 50% 时攻击获得 100% 吸血。
- `attackCardsPlayed`：本回合/本局用于裂牙补刀生成判断的攻击牌计数。

### 敌人状态

- `armorBreak`：破甲回合数，存在时攻击忽略目标护甲。
- `stunned`：眩晕回合数，存在时跳过一次敌方行动。
- `block`：当前护甲。

## 4. 结算顺序

```text
选择目标 → 支付费用 → 处理卡牌基础效果 → 处理狂怒/能力状态
→ 结算伤害与护甲 → 处理吸血/生成牌 → 写入战斗日志
```

敌方回合：

```text
眩晕检查 → 敌方意图行动 → 玩家护甲/承伤 → 反伤 → 张飞受击狂怒 → 回合状态清理
```

## 5. 验收标准

1. 破甲目标的后续攻击可以无视其护甲，并在状态结束后恢复正常。
2. 眩晕目标会跳过一次行动，且不会在同一回合重复行动。
3. 反伤在玩家实际受到伤害后触发，护甲完全抵挡时不产生反伤。
4. 低于 50% 兵力时，狂血奔涌与浴血疯魔的效果能被战斗日志验证。
5. 狂刃连斩、裂牙补刀、千刃狂潮的段数和生成逻辑可重复验证。
6. 燕人血脉不会让狂怒超过 15 层，普通状态不会超过 10 层。
7. 多敌人场景下，所有状态只作用于正确的玩家或当前目标。
