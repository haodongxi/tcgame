# MVP13 状态徽标与 Boss 战斗反馈

> Created by: haodongsheng  
> Version: 1.3  
> Date: 2026-08-20

## 1. 本轮目标

把 MVP12 已经生效的状态规则显性化，让玩家不需要只依赖战斗日志判断当前战场状态。

## 2. 状态展示

敌方单位卡片显示：

- 破甲：当前破甲回合数。
- 眩晕：剩余无法行动回合数。
- 灼烧：当前灼烧层数。
- 暴走：Boss 进入低血量阶段后显示。

敌方意图显示：

- 张宝：黄天符法或符法护甲。
- 华雄：斩击与破甲提示。
- 高顺：召唤死士提示、死战阶段通过攻击数值体现。

## 3. 视觉规则

- 普通状态使用金色徽标。
- 伤害、破甲、灼烧、暴走使用朱红色徽标。
- 眩晕、虚弱等控制状态使用蓝色徽标。
- 状态徽标允许换行，不撑高敌人卡片到超出战斗区域。
- 移动端缩小字号和间距，保证多个敌人仍能横向并列显示。

## 4. 交互反馈

状态变化后随战斗局部刷新立即更新：

1. 出牌造成破甲或眩晕，目标徽标即时出现。
2. 敌方回合结束后，眩晕、灼烧、虚弱层数即时减少。
3. Boss 到达特殊回合时，敌方意图文案提前提示核心技能。
4. 已击破敌人保留灰度状态和历史徽标区域，避免敌人组布局跳动。

## 5. 验收标准

1. 破甲、眩晕、灼烧、暴走状态可在对应敌人卡片上看到。
2. 张宝、华雄、高顺的特殊意图能在行动前显示。
3. 多敌人状态徽标不会遮挡兵力、血条和目标选择边框。
4. 手机端不出现横向页面滚动或新的纵向滚动。
5. 普通战和精英战仍保持原有目标选择与结算流程。
6. `node --check web/src/app.js` 与 `git diff --check` 通过。
