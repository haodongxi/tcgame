# 三国肉鸽卡牌 Web MVP 0.3：构筑与成长

> Created by: haodongsheng  
> Version: 0.3  
> Date: 2026-08-19  
> 基于：`doc/MVP2路线与构筑.md` 与当前 `web/` 可玩版本

## 1. 本轮目标

MVP 0.2 已经验证路线、事件、黑市和牌组延续。本轮验证两个更长期的问题：

1. 玩家能否通过遗物和强化牌形成清晰的 Build 方向？
2. 失败后获得的永久材料是否能转化为下一局的可感知成长？

本轮不扩展章节数量，先让一章内容产生更强的重复游玩价值。

## 2. MVP 0.3 范围

### P0：必须完成

| 功能 | 规则 | 验收 |
| --- | --- | --- |
| 遗物 | 精英战胜利后先选择 1 件遗物，再选择战斗奖励牌 | 遗物至少有 3 件，效果能在战斗中观察到 |
| 卡牌强化 | 休整节点可选择强化一张牌；强化牌保留到本局结束 | 牌面有强化标记，效果数值发生变化 |
| 中军大帐 | 标题页进入，展示兵革残片和永久天赋 | 可以消费永久材料，不依赖当前局 |
| 永久天赋 | “锐兵”三级，每级提高所有主将初始/上限兵力 50 | 下一局开始时兵力上限立即变化 |
| 遗物展示 | 战斗页显示当前遗物 | 玩家不用打开额外菜单即可知道 Build |
| 失败反馈 | 失败结算说明保留永久材料，局内强化/遗物清空 | 重新出征不污染上一局 |

### P1：本轮暂不做

- 遗物随机词条和稀有度
- 卡牌多等级和升级费用
- 完整天赋树前置关系
- 将魂、羁绊和多章节内容
- 云端存档与跨设备同步

## 3. 遗物设计

| 遗物 | 获取 | 效果 |
| --- | --- | --- |
| 《孙子兵法》 | 精英战胜利 | 每场战斗第一回合气力 +1 |
| 青釭剑 | 精英战胜利 | 武技第一次造成伤害时额外 +10 |
| 行军干粮 | 精英战胜利 | 每场战斗开始回复 20 兵力 |

遗物只作用于当前局，不进入永久存档。重复获得同一遗物时，本轮仍允许重复展示但不重复叠加，直接进入下一步选择。

## 4. 卡牌强化

强化优先覆盖基础牌和三名主将的核心牌：

| 卡牌 | 普通效果 | 强化效果 |
| --- | --- | --- |
| 挺矛直刺 | 55 伤害 | 70 伤害 |
| 列阵防御 | 40 护甲 | 55 护甲 |
| 厉兵秣马 | 抽 2 张 | 抽 3 张 |
| 干粮 | 回复 30 | 回复 45 |
| 横扫千军 | 80 伤害 | 105 伤害 |
| 咆哮突进 | 60 伤害、狂怒 +2 | 80 伤害、狂怒 +3 |

为了保持 MVP 简单，强化以“卡牌 ID 全局强化”实现，同名卡牌会一起强化；未来再拆分为独立卡牌实例。

## 5. 中军大帐

### 韬略阁：锐兵

| 等级 | 消耗兵革残片 | 效果 |
| ---: | ---: | --- |
| 1 | 40 | 初始/上限兵力 +50 |
| 2 | 80 | 初始/上限兵力 +100 |
| 3 | 140 | 初始/上限兵力 +150 |

MVP 只实现一条天赋，目的是验证“战败—材料—购买—下一局”的最小元成长闭环，而不是一次铺开完整天赋树。

## 6. 状态模型约束

```text
metaProgress: 永久材料、永久天赋
runState:     当前牌组、铢钱、兵力、遗物、强化牌
battleState:  当前战斗的手牌、抽牌堆、敌人、日志
```

- `metaProgress` 写入 `localStorage`。
- `runState` 在开始新局时重建。
- `battleState` 在进入下一场战斗时重建。
- 遗物效果必须通过少量集中函数触发，不能散落在页面渲染逻辑中。

## 7. 验收场景

1. 中军大帐购买一级锐兵，开始新局后主将上限兵力增加 50。
2. 休整选择强化，下一场战斗中强化卡牌显示“强化”，且伤害/护甲/抽牌数变化。
3. 精英战胜利后选择《孙子兵法》，下一场战斗第一回合气力为 4。
4. 选择青釭剑后，武技首击额外造成 10 伤害，后续攻击不重复触发。
5. 选择行军干粮后，战斗开始日志显示回复 20 兵力。
6. 失败后重新出征，遗物和强化牌清空，但永久天赋和兵革残片保留。
7. 手机和电脑端都能看到当前遗物，奖励弹窗不超出屏幕。

## 8. 完成定义

- 文档和代码中的状态分层一致。
- 三件遗物至少有两件能影响战斗数值或日志。
- 至少六张牌支持强化。
- 永久天赋购买成功后能影响下一局。
- JavaScript 语法检查通过，工作区有清晰的本地提交。
